# Pushing this project to GitHub

## 1. Create the repo on GitHub
1. Go to https://github.com/new
2. Repository name: `job-market-intelligence`
3. Keep it **Public** (so recruiters/interviewers can see it)
4. Do NOT initialize with a README, .gitignore, or license (you already have these)
5. Click **Create repository** — GitHub will show you a repo URL like
   `https://github.com/<your-username>/job-market-intelligence.git`

## 2. Push your local project
Open a terminal in the project's root folder (`job-market-intelligence/`,
the one containing `README.md`, `backend/`, `frontend/`, `data-pipeline/`)
and run:

```bash
git init
git add .
git commit -m "Initial commit: Job Market Intelligence Platform"
git branch -M main
git remote add origin https://github.com/<your-username>/job-market-intelligence.git
git push -u origin main
```

Replace `<your-username>` with your actual GitHub username.

## 3. Double-check your API key never got committed
Before pushing, confirm `backend/.env` (if you created one) is NOT tracked:
```bash
git status
```
It should NOT list `.env` — `backend/.gitignore` excludes it. If you
already committed a real key by accident, rotate it immediately at
https://console.anthropic.com/settings/keys (delete the old key, create
a new one) rather than just removing it from a future commit.

## 4. What should be in the repo
Everything in this project folder is meant to be committed **except**:
- `backend/node_modules/` and `frontend/node_modules/` (regenerated by `npm install`)
- `frontend/dist/` (regenerated by `npm run build`)
- `backend/.env` (your real API key — never commit this)

`data-pipeline/job_market.db` and `raw_job_postings.csv` SHOULD be
committed — they're small and let anyone clone the repo and run it
immediately without regenerating data first.

## 5. Write a good repo description
On the GitHub repo page, click the gear icon next to "About" and add:
- **Description**: "End-to-end data pipeline + REST API + React dashboard analyzing job market skill trends, salary bands, and skill gaps — with an AI-powered learning plan via the Claude API"
- **Topics**: `data-analysis`, `sql`, `react`, `nodejs`, `express`, `data-pipeline`, `claude-api`
- Add your live Vercel link (see `docs/deployment.md`) in the website field
